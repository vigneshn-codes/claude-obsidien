# Concept — Divergent vs Convergent Thinking

**Source book:** $100M Offers
**Type:** Cognitive framework
**Related concepts:** Trim & Stack, Grand Slam Offer

## Definition
Hormozi borrows the classic creativity distinction:

- **Convergent thinking** — one right answer. Math, code, accounting, logistics.
- **Divergent thinking** — many right answers. Marketing, offer design, naming, branding.

Offer design is *divergent*. Treating it as *convergent* is the most common mistake.

## Why It Matters for Offers
There is no single "correct" offer. There is a population of possible offers, each with different value scores. The goal is to:
1. **Generate** many candidates (quantity).
2. **Score** them (using the Value Equation).
3. **Trim** to the strongest.

Founders who think convergently freeze trying to find *the* offer. Founders who think divergently iterate quickly.

## The Workflow
1. **Diverge** — brainstorm 20+ possible deliverables, bonuses, naming options, guarantees.
2. **Don't judge yet** — premature filtering kills the best ideas.
3. **Score** — apply the Value Equation lens.
4. **Converge** — pick the top combination.
5. **Ship** — and iterate.

## Application Beyond Offers
- **Lead magnets** — generate 10 narrow-problem ideas, pick the most painful.
- **Hooks** — write 30 ad headlines, run the top 3.
- **Names** — brainstorm 50 program names, run gut + MAGIC formula.
- **Bonuses** — list 20 possible bonuses, stack 5.

## The Cognitive Switch
Hormozi recommends **time-boxing the mode**:
- 25 minutes pure divergent (no judgment).
- 25 minutes pure convergent (ruthless filtering).
- Never mix the two in the same sitting.

## Anti-Pattern
Trying to write the "perfect" first draft. The perfect offer doesn't exist as a single inspired insight — it's the survivor of 50 weaker siblings.
