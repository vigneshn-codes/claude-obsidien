# Lead Magnet

**Summary:** A complete solution to a narrow problem, given away free in exchange for contact info and engagement — the highest-leverage activity when a business is stuck on leads.

**Category:** Lead Generation
**Sources:** `11-concept-lead-magnet.md`, `02-100m-leads.md`, `05-key-frameworks.md`
**Related:** [[core-four]], [[value-equation]], [[grand-slam-offer]], [[engaged-leads]]

---

## The Three Tests

A lead magnet works only if it passes all three:

1. Solves a **specific** problem the prospect actually has (not a general one)
2. Is **immediately usable** — no setup barrier, under 20 minutes to value
3. Is **valuable enough that someone would pay for it** — if you wouldn't sell it, no one wants it free

> "If you're struggling to get leads, make an amazing lead magnet."

---

## Six Types of Lead Magnets

| Type | Examples | Best For |
|---|---|---|
| **Software / tool** | Calculator, template, mini-app, tracker | Tech-savvy audiences; high shareability |
| **Information** | Guide, ebook, video training, swipe file | Education-hungry audiences |
| **Service** | Free audit, free consultation, done-for-you element | High-ticket, trust-building contexts |
| **Sample of product** | Trial period, sample workout, demo session | Proving the core offer before commitment |
| **Checklist / template** | Operational shortcut, fill-in-the-blank framework | Anyone who wants to save time |
| **Community / event** | Challenge, webinar, mini-cohort | Audiences that value accountability and belonging |

---

## The 5-Step Build

1. **Identify the ideal prospect** — specific avatar (see [[starving-crowd]])
2. **Identify a narrow problem** — not "get fit," but "write 3 compound lifts into a weekly program without overlapping muscle groups"
3. **Pick the type** — match type to avatar's preferences
4. **Make it valuable** — would someone pay $50–$500 for this? If not, it's not good enough
5. **Make it easy to consume** — under 20 minutes to value; no prerequisites

---

## The Conversion Sequence

```
Reach → Lead Magnet Hook → Opt-in → Delivery → Consumption → Offer
```

A lead is only "engaged" once they've **consumed** the lead magnet — not when they opted in. Opt-in is not a lead. Engagement is a lead.

---

## Common Failure Modes

| Failure | Description |
|---|---|
| Too broad | "The Ultimate Guide to Fitness" — nobody knows if it's for them |
| Too long | 50-page PDF nobody reads; value never lands |
| Solves an unknown problem | Prospect doesn't yet know they have this problem; they won't opt in |
| Solves the problem completely | No logical reason to buy the core offer afterward |
| Weak hook | Correctly designed magnet, badly named and badly distributed |

## Lead Magnet Ideas for Workout / Fitness Software

| Lead Magnet | Narrow Problem It Solves | Type |
|---|---|---|
| "1-Rep Max Calculator + 12-Week Training Weight Planner" | "I don't know what weights to use" | Software/tool |
| "The 4-Week Beginner Lifting Template (PDF)" | "I don't know how to start" | Checklist/template |
| "Free Workout Log App (7-day trial)" | "I track workouts in Notes and it's a mess" | Sample of product |
| "The Plateau Diagnostic: 5 Questions to Find Out Why You've Stopped Progressing" | "I've been stuck on the same weights for months" | Information |
| "The 30-Day No-Gym Challenge" | "I can't get to the gym consistently" | Community/event |
| "Free Gear-Free Strength Assessment" | "I don't know my starting fitness level" | Service |
